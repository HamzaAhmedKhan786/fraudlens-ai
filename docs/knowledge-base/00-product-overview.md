# What is FraudLens AI?
FraudLens AI is a multi-tenant fraud investigation application supporting case management, evidence intake, deterministic fraud-risk scoring, cited reports, and human review.

# What is a risk score?
The risk score is a deterministic indicator from 0 to 100. It does not prove fraud, and an LLM cannot set or change it.

# What can the product guide do?
It explains documented navigation and workflows. It cannot inspect case evidence, modify records, or make fraud decisions. Evidence questions belong to the authorized case copilot.
