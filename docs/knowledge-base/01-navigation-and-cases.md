# Where are the main sections?
The workspace includes Overview, Cases, Evidence intake, Investigations, Entity graph, Review queue, Public intelligence, Email connectors, Agent activity, Detection policies, Model health, Workspaces, Team, Billing, Settings, Trash, and Audit trail.

# How do I start an investigation?
Use New Investigation, select the workflow and detectors, create the case, add evidence, and explicitly run analysis. Creating a case does not mean analysis has finished.

# Why are metrics empty?
Check API connectivity and persisted data. Unavailable data or zero activity does not prove that no threats exist.
