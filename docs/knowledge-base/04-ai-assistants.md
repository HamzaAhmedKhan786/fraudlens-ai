# What is the product guide?
The guide retrieves verified product documentation and provides cited navigation help. It does not inspect customer evidence or modify application data.

# What is the case copilot?
The case copilot operates inside an authorized case using evidence and the latest report. It cites evidence IDs and cannot change scores or disposition.

# Why can’t the guide answer a case question?
The guide has no case evidence access by design. Open the relevant case and use its copilot if authorized.
